文字サイズを大きくした設定でも表示が崩れないように直したリリースです。

## バス停名の出し方を変えました

**画面に出すのは短縮名（`本部棟`）にし、正式名（`科技大本部棟`）はタップで出す**
形に統一しました。v1.3.1 で「到着行やカードの見出しに正式名を出す」ようにしたばかりの
場所ですが、正式名は長いものだと13文字（`古泉循環器内科クリニック前`）あり、
**文字を拡大している端末では入り切らずに切れてしまう**ことが分かったためです。

短縮名は最長でも5文字なので幅の問題そのものが無くなり、正式名は
**タップすれば必ず全部読める**ようになりました。

- **到着行を短縮名に戻し、タップで正式名と時刻を出すようにしました** (#241)
  - `古泉循環器内科クリニック前 着` → `古泉 着`。タップすると1行下に
    `古泉循環器内科クリニック前 09:30` が開きます
  - NEXT BUS カード・ホームの時刻表リストの両方が対象です
- **節の見出し（`◯◯ 発`）を短縮名に戻し、タップで正式名に切り替わるようにしました** (#245)
  - こちらは行を増やさず、その場で表示が入れ替わります

## 修正

- **文字を拡大したときに、バス停タブの中身が縦に溢れる不具合を修正しました** (#240)
  - 拡大しているときだけカードの余白を詰めるようにし、Android の文字サイズ「最大」
    （拡大率 1.3 相当）までは詰めるだけで収まるようにしました。それを超える倍率では
    画面ごとスクロールできるように切り替わります
- **時刻表リストの行ヘッダが文字拡大時に横へ溢れる不具合を修正しました** (#242)
  - 時刻・講義タグ・行き先・系統タグが固定幅で並んでいて縮む余地がなかったため、
    中間の3つを折り返せるようにしました
- **横スクロール（タブの切り替え）で意図せず画面が縦に動くことがあるのを直しました** (#260)
  - 縦方向のドラッグを止める仕組みがタブの一部にしか掛かっておらず、余白を掴んで
    横にスワイプすると縦にも動いていました。各タブの最外周に移し、常時掛かるようにしています

## テスト

- **文字拡大の計測を、行き先が2方向ある停留所（研究棟など）にも広げました** (#251)
  - これまで1方向の停留所だけで測っており、方向を選ぶボタンが出る分の高さを
    見落としていました。**表示や動作の変更はありません**（テストと記録の整備です）

上記の修正により、**実際の端末のフォントで測った範囲では、拡大率 2.0 まで
表示の溢れが出なくなりました**（到着行をすべて開いた状態を含む）。

## 既知の問題

- 節の見出しを**タップして正式名を出した状態**は、Android の「大」（拡大率 1.15 相当）
  あたりから末尾が省略されます。正式名は「タップすれば全部読める」ことを目的にした
  表示のため、高倍率で1行に収まることまでは想定していません
- 到着行や見出しが**タップできること自体は画面上に示していません** (#258)
