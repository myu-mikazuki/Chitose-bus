2026年10月1日（令和8年10月1日）のダイヤ改正に対応したリリースです。

## 新ダイヤに差し替えました

- **10月1日からの新ダイヤに切り替わります** (#253)
  - 千歳市が公開した令和8年10月改正の時刻表（平日・土日祝）に合わせて、全便を入れ替えました
  - **新系統「南17」（南千歳駅北口 ⇔ 科技大 ⇔ ラピダス）を追加しました**
  - 停留所に **南千歳駅北口** を追加しました
  - 直17 の千歳駅のりばが **3番 → 4番** に変わりました
  - 切り替えはアプリの更新ではなく**サーバー側のデータ差し替え**で行い、10月1日に合わせて実施します。日付で自動的に切り替わる仕組みではありません。差し替え後は、アプリを更新していない端末にも新ダイヤが表示されます（ただし南17 の復路は、このリリースのアプリでのみ表示されます）

## 修正

- **時刻表リストの行き先が、NEXT BUS・見出しと食い違うことがあるのを直しました** (#270)
  - 南17 の復路は南千歳駅北口が終点ですが、リストの行は「南千歳行き … 千歳駅」と

  - 往路の行は「科技大」から「本部棟」の表記に変わります（NEXT BUS と同じ表記）
