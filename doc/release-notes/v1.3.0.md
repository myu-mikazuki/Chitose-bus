## 新機能

- **乗車地にするバス停を選べるようにしました** (#177)
  - 設定 →「バス停」→「**タブに表示するバス停**」から、路線上のバス停を選んで並べ替えられます。並べた順がそのままタブの並びになります
  - 初期設定は従来の **千歳駅 / 南千歳 / 研究棟 / 本部棟** の4つです。**設定を触らなければ表示はこれまでと変わりません**
  - 選べるのは **5件まで** です (#204)
    - 375px 幅の端末で実測すると、6タブではラベルに残る幅が 14.5px しかなく、最も短い短縮名でも `…` だけになります（5タブなら 27.0px で `研…` まで出ます）
    - **足していくのではなく入れ替えて使うもの**として考えてください。上限に達した設定画面も「別のバス停にするには外す」と促します
  - 千歳駅ののりば番号は、乗車地が千歳駅のときだけ表示します

- **祝日ダイヤを、アプリ自身が判定するようになりました** (#173)
  - 平日に当たる祝日（山の日など）を土日祝ダイヤとして扱います。v1.2.0 で**既知の問題 (#158) として挙げていたもの**の解消です
  - v1.2.0 まではアプリ側に祝日の判定が無く、**サーバ側で絞った結果を受け取ることで成立していました**。そのため、オフラインのときや古いキャッシュを表示している間は平日ダイヤのままでした。アプリが判定できるようになったことで、この場合も正しく出ます
  - 時刻表の注記どおり、**4/29・7/20・10/12・11/3・11/23 は「祝日だが平日ダイヤ」**として引き続き平日扱いにします

## 時刻表の修正

- **復路の南千歳着を修正しました** (#167, #176)
  - 本部棟発 **17:52 / 19:02 / 20:32 / 22:02** の南千歳着を一度削除しましたが、**これは PDF の読み違いによる誤りでした**。大学配付の「美々空港線 学休期ダイヤ（修正版）」に 18:07 / 19:17 / 20:47 / 22:17 が明記されていたため復元しています
  - あわせて、**学休期だけ 15:24 本部棟発（15:27 研究棟発）が南千歳を通過する**という扱いも取り消しました。修正版には学休期でも南千歳 15:39 が明記されているためです。授業期・学休期で差が無くなりました

> [!NOTE]
> 時刻表の中身はサーバ側（GAS）が持っているため、**この修正はアプリを更新していない利用者にも、サーバ更新の時点で反映されます。**

## 更新後の初回起動について

- 時刻表の取得形式が変わりました（`?v=4`）。1便を乗車地ごとに展開する形をやめ、**1便を1件**として停留所と時刻の並びをそのまま受け取ります。全31停留所を旧形式で扱うと約 1MB になるためです（新形式なら約 35KB、既定の4停留所では約 17KB と旧形式の約 31KB より小さくなります）
- **更新後の初回起動でも、オフラインで時刻表を表示できます。** v1.3.0 より前のキャッシュは移行用の経路で読めるようにしてあるため、通信できない状態で起動しても空振りしません (#186)
- この移行用の経路は **v1.4.0 で削除します** (#186)

## 修正

- **旧形式の応答でキャッシュが空に上書きされるのを防ぎました** (#201)
  - サーバ側が旧形式を返した場合（デプロイ前・ロールバック時）、これまでは空のキャッシュが保存され、**再インストールするまで復旧しない**状態になり得ました
  - 旧形式は保存せず、その場で解釈して表示するようにしました。この間は既定の4停留所ぶんに表示が落ちます

- **v1.1.0 以前のアプリで「当日以外のダイヤ」が空になる問題を直しました**
  - v1.1.0 以前（`?v=1`）向けの応答を、運行日で**毎日**絞り込んでいました。「当日以外のダイヤ」は同じデータをアプリ側で絞り直す作りのため、切り替えた側が 0 件になります（土曜に平日ダイヤを見ると 43便すべてが消える）
  - 絞り込むのは、アプリ側の曜日判定と食い違う「平日に当たる祝日」のときだけにしました
  - **サーバ側の修正なので、v1.1.0 以前を使い続けている利用者にもサーバ更新の時点で反映されます**（v1.3.0 に更新する必要はありません）

## 既知の問題

- 短縮名を持つのは既定の4停留所だけです (#207)。新しく選べるようになったバス停は「古泉循環器内科クリニック前」のような正式名がそのまま出るため、**上限まで使うほどタブの名前は読みにくくなります**。NEXT BUS カード側にバス停名を出すことも検討中です (#208)
- 更新前のキャッシュを表示している間は、学休期でも授業期の便が出ることがあります (#172)。この場合は「キャッシュデータを表示中」のバナーが出ます
- 同時刻・別系統の便で通知キーが衝突します (#190)。v1.3.0 で入った不具合ではありません
