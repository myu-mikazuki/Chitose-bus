## 新機能

- **美々空港線の学休期ダイヤに対応しました** (#132, #157)
  - 公立千歳科学技術大学の学休期間中、美々空港線は「学休期ダイヤ」で運行します。対象期間に入ると自動で学休期の時刻表を表示するようになりました
    - 夏季: 8月第1月曜日 〜 9月第4週金曜日
    - 冬季: 2月第1月曜日 〜 3月31日
    - お盆: 8/13 〜 8/16
  - 学休期は千歳駅からの直通便（直17系統）が **往路 19便 → 6便、復路 9便 → 4便** に減便されます。これまでは授業期の時刻表を表示していたため、実際には運行しない便が表示されていました
  - 空港経由（空17系統）の 15:24 本部棟発は、学休期のみ南千歳駅を経由しません
  - 学休期は画面上部にその旨をバナー表示します
  - 「当日以外のダイヤ」表示に、授業期 / 学休期の切り替えを追加しました
- **年末年始（12/31 〜 1/3）の全便運休に対応しました** (#132, #157)
  - 運休期間中はその旨を表示し、時刻表を出さないようにしました

## 変更

- **時刻表の有効期間表示を削除しました** (#147, #160)
  - 画面下部が「更新: ○○ 有効期間: ○○ 〜 ○○」から「更新: ○○」になりました。有効期間が固定値で意味を成さなくなっていたためです

## 内部改善

- **GAS のレスポンスをスキーマバージョンで出し分けるようにしました** (#157)
  - GAS は手動デプロイ、アプリはストア審査を挟むリリースのため反映タイミングが必ずずれ、更新しないユーザーの旧バージョンは永続的に残ります。リクエストの `?v=` で応答形式を切り替えることで、旧バージョンのアプリでも正しい時刻表が表示されるようにしました
  - 以後、GAS のデプロイ順を気にする必要がなくなります
- **GAS のスクリプトキャッシュを廃止しました** (#153, #154)
  - コードを更新しても旧データが配信され続ける問題を解消しました
- 期別判定の実装がアプリ側と GAS 側でずれないよう、境界値を検証するチェックを CI に追加しました (#157)

## 既知の問題

- 祝日ダイヤの判定は未実装です (#158)。平日に当たる祝日は平日ダイヤとして扱われます。なお 4/29・7/20・10/12・11/3・11/23 は時刻表上「祝日だが平日ダイヤ」で運行するため、結果的に正しく動作します
